# 一键启动脚本

Windows 下可直接双击根目录 `start.bat` 启动网页端。脚本会自动完成以下步骤：

```text
1. 进入项目目录
2. 检测本机 Python（优先 py -3，其次 python）
3. 创建或复用 `.venv` 本地 Python 环境
4. 安装 `requirements.txt` 依赖
5. 检查监听端口是否被占用；如被占用，自动结束占用该端口的进程
6. 延迟约 2 秒后打开浏览器访问 `http://127.0.0.1:端口`
7. 启动 `web.py`
```

默认监听 `127.0.0.1:18765`。如需改监听地址或端口，可在启动前设置环境变量：

```bat
set PAYPAL_WEB_HOST=0.0.0.0
set PAYPAL_WEB_PORT=18765
start.bat
```

端口清理只处理当前配置端口的 `LISTENING` 进程，不会扫描或关闭其他端口。若该端口被其他重要程序占用，请先改 `PAYPAL_WEB_PORT` 再启动。

首次启动会创建 `.venv` 并安装依赖，耗时更长；后续启动会复用已有环境。

停止服务时，在启动窗口按 `Ctrl+C`。

浏览器辅助登录（Playwright Chromium）不在启动阶段强制安装；只有任务走到有头浏览器辅助时，才会按需安装。
